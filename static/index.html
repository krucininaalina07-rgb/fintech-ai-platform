Управление подпиской

Выберите уровень доступа, который соответствует вашим задачам. Все тарифы включают базовую рыночную аналитику и объяснимость прогнозов.

Базовый
1 500 – 2 700 ₽ / мес
Для частных инвесторов, которые только начинают.
  • Портфель до 25 млн рублей
  • Ограниченная верификация (3–5 проверок в месяц)
  • Базовый цифровой двойник
  • Объяснимость прогнозов и уведомления
Популярный
Профи
3 000 – 5 000 ₽ / мес
Для активных трейдеров и профессионалов.
  • Неограниченный размер портфеля
  • Приоритетная верификация экспертами
  • Полный доступ к цифровому двойнику
  • Экспорт отчётов и API для интеграции
Корпоративный
от 100 000 – 300 000 ₽ / мес
Для фондов, банков и команд аналитиков.
  • Командный доступ с разделением прав
  • Журнал всех решений (аудит)
  • Выделенный эксперт-консультант (SLA)
  • Персональный менеджер и API
